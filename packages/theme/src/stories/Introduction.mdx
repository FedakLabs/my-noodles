# my-noodles design system

Storybook is the **living visual reference** for `packages/theme`. It renders the same MUI `theme` object that `apps/web` imports — not a duplicate palette.

**Decisions and rules** live in [`docs/design-system-brief.md`](../../../docs/design-system-brief.md) (why). **Tokens and components** live in `packages/theme/src` (what).

## Source of truth

1. Change tokens in `palette.ts`, `typography.ts`, `components.ts`, etc.
2. Stories here update automatically via `ThemeProvider` in `.storybook/preview.tsx`.
3. Ship the same exports to the storefront.
